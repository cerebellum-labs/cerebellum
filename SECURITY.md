# Security policy

## Reporting

Please report security issues privately through GitHub: **Security → Report a vulnerability** on [cerebellum-labs/cerebellum](https://github.com/cerebellum-labs/cerebellum/security/advisories/new). Do not open a public issue.

Include what you ran, what happened and what you expected. We aim to reply within 5 working days.

## Supported versions

Cerebellum is pre-1.0. Fixes go to `main` and ship in the next release of each package; older releases are not patched, so update to the latest one.
